T-SHIRT LOOKBOOK — PNG SETUP

1. Extract this ZIP file.
2. Open the images folder.
3. Put your 14 PNG image files in that folder and rename them exactly as below.
4. Double-click index.html to open your lookbook in Chrome, Edge, or Firefox.

IMAGE FILE NAMES:
design-01-front.png
design-01-back.png
design-02-front.png
design-02-back.png
...
design-07-front.png
design-07-back.png

IMPORTANT:
- Keep index.html and the images folder together.
- The image order is 01 to 07.
- Front/back buttons switch the view for the selected T-shirt.
- Use arrow buttons, keyboard arrows, thumbnail numbers, or swipe on mobile.
- For a public shareable link, upload the extracted folder to a static hosting service such as Netlify Drop.
